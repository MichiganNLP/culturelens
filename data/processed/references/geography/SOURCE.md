# Country geography reference

`countries.csv` holds each country's ISO3 code, common name, centroid latitude and
longitude, region and subregion.

- Source: mledoze/countries, `countries.json`
  (https://github.com/mledoze/countries), commit `c2ac0049c14edcf2436c7aa1b2493222a020b462`.
- Source file SHA-256: `913e5d716f9dc6b59881ee23488d47f5fda52070d1a34cac5fa327c9e61d8f7c`.
- License: Open Database License (ODbL) 1.0.
- Derivation: the six fields above, copied unchanged and sorted by ISO3.

Used only as a control in the WVS RSA (geographic distance and shared region).
